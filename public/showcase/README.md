# Showcase images

หน้า `/showcase` จะ **สแกนไฟล์รูปอัตโนมัติ** จาก 4 โฟลเดอร์หมวดหมู่ด้านล่างนี้
ไม่ต้องแก้โค้ด ไม่ต้องตั้งชื่อไฟล์ตายตัว — แค่ลากรูปไปวางในโฟลเดอร์ที่ตรงหมวดก็พอ

```
public/showcase/
├── ea/          → หมวด "EA / ระบบเทรดอัตโนมัติ"
├── promotion/   → หมวด "โปรโมชั่น"
├── seminar/     → หมวด "สัมมนา / กิจกรรม"
└── concept/     → หมวด "Mindset & Knowledge"
```

## วิธีอัพรูปเอง

1. เลือกโฟลเดอร์หมวดที่ตรงกับรูป (เช่น โปรโมชั่นใหม่ → `public/showcase/promotion/`)
2. ลากไฟล์รูป (.png / .jpg / .jpeg / .webp / .gif) วางในโฟลเดอร์นั้นได้เลย
3. ตั้งชื่อไฟล์ตามที่อยากให้ขึ้นเป็นหัวข้อใต้รูป เช่น `โปรโมชั่นเดือนกรกฎาคม.png`
   จะแสดงเป็นหัวข้อ "โปรโมชั่นเดือนกรกฎาคม" อัตโนมัติ (เครื่องหมาย `-` หรือ `_` ในชื่อไฟล์
   จะถูกแปลงเป็นช่องว่าง)
4. มีกี่ไฟล์ก็ใส่ได้หมด ระบบจะแสดงทุกไฟล์ในโฟลเดอร์ เรียงตามชื่อไฟล์

## หมายเหตุ

- ถ้าโฟลเดอร์หมวดไหนยังว่างอยู่ (ยังไม่มีรูปจริง) ระบบจะแสดงตัวอย่างผลงาน demo
  (ดึงรูปจาก Google Drive) แทนโดยอัตโนมัติ — พอมีไฟล์จริงในโฟลเดอร์นั้นเมื่อไหร่
  ตัวอย่าง demo จะหายไปเองและรูปจริงจะขึ้นมาแทน
- ไฟล์ `.gitkeep` ในแต่ละโฟลเดอร์มีไว้ให้ Git เก็บโฟลเดอร์เปล่าไว้ ไม่ต้องลบทิ้ง
  (ใส่รูปเพิ่มในโฟลเดอร์เดียวกันได้ตามปกติ)
- ถ้าต้องการแก้หมวดหมู่/ข้อความบรรยายของ demo เดิม แก้ได้ที่ `app/showcase/data.ts`
  (ตัวแปร `FALLBACK_ITEMS`)
